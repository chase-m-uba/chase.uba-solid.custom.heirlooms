Heirloom Bed

Interactive 3D models — orbit, zoom, pan, isolate subsystems, and toggle layers right in your browser. No install; works on desktop and mobile.

Live viewer: chase-m-uba.github.io/custom.heirloom.bedframe.viewer/
If you are browsing these files on GitHub's code view instead, the 3D models will not run there — that view only shows the file source. Open the link above (GitHub Pages), or download the repo and double-click index.html.
